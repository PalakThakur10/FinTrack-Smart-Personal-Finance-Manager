Viva Reference
Abstraction & Pure Virtual Functions:
Base class Transaction with pure virtual methods virtual double calculateImpact() = 0; and virtual void display() = 0;.
Inheritance & Method Overriding:
class Income : public Transaction and class Expense : public Transaction override calculateImpact() (+amount for Income, -amount for Expense).
Dynamic Polymorphism:
FinanceManager processes polymorphic vectors std::vector<std::shared_ptr<Transaction>> computing net balance polymorphically at runtime.
Encapsulation & Validation:
Protected and private fields with strict accessor methods enforcing domain constraints (amounts > 0, valid dates, hashed passwords).
Function Overloading:
Multiple overloaded implementations of getTransactions() and constructors across models and services.
